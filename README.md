# SandeepKomal.github.io

Personal portfolio for Sandeep Komal — Cloud, DevOps and DevSecOps engineering.
Live at https://sandeepkomal.github.io/

## Layout

| Path | What it is |
| --- | --- |
| `site-src/` | Source for the main site (React, TypeScript, Tailwind CSS, Framer Motion, Three.js) |
| `index.html`, `app/` | The built main site — generated by `npm run build`, do not edit by hand |
| `classic/` | The previous HTML/CSS portfolio, kept at `/classic/` |
| `3d/` | Redirects the old `/3d/` link to the home page |

## Editing the site

All text, links, projects and the tool stack live in `site-src/src/content.ts`.

```bash
cd site-src
npm install
npm run dev      # preview at http://localhost:5173
npm run build    # writes index.html and app/ in the repo root
```

Commit the rebuilt `index.html` and `app/` together with your source changes, then push to `main`.

## Deploy

Pushing to `main` publishes the site with GitHub Pages. The built files are committed, so it works with
**Settings → Pages → Source** set to either **Deploy from a branch** or **GitHub Actions**
(GitHub Actions is recommended, so only one deploy runs per push).
