# SandeepKomal.github.io

Personal portfolio for Sandeep Komal — Cloud, DevOps and DevSecOps engineering.

## Highlights

- Responsive dark engineering-focused portfolio
- Featured projects and technology stack
- Downloadable CV
- GitHub, LinkedIn and Medium links
- GitHub Pages deployment through Actions
- No framework or runtime dependency required

## Personalize before publishing

Update these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- LinkedIn URL
- Medium URL

Add the CV as:

```
assets/Sandeep-Komal-CV.pdf
```

## Deploy

1. In GitHub, open **Settings → Pages**.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Push changes to `main`; the included workflow deploys the site automatically.
